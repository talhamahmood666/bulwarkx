
# Security Policy
Security is a top priority for the BulwarkX project.

# Supported Versions
The project is in active development. Security fixes will generally be applied only to the main branch and recent tagged releases.

# Reporting a Vulnerability
If you believe you have found a security vulnerability in the codebase or deployed contracts:

## Email us at: bulwarkx@proton.me
## Include:

### A detailed description of the issue

### Steps to reproduce

### Any relevant logs, transaction hashes, or PoC code

### Assessment of potential impact

## Please do not open a public GitHub issue for critical vulnerabilities before we have had a chance to investigate and patch.

## We will make a best effort to:

### Acknowledge receipt within a reasonable timeframe

### Investigate and validate the issue

### Provide an estimated timeline for remediation

### Credit you (if you wish) after the fix is deployed and publicly disclosed

# Scope
This security policy covers:

Smart contracts in the contracts/ directory

The BulwarkX processor and SDK code as deployed in official releases

Officially maintained plugins and integrations

Third-party deployments, forks, and unofficial integrations may not be in scope.

Responsible Disclosure
We strongly encourage responsible disclosure practices and appreciate researchers who work with us to keep users safe.
