BulwarkX PrestaShop Module (MVP)
================================

Install
-------
1. Copy the `bulwarkx` folder into your PrestaShop `/modules` directory.
2. Install and enable the module from the PrestaShop back office.
3. Configure API Base URL, payee address, arbiter address, and auto-release seconds in the module settings.

Usage
-----
During checkout, choose BulwarkX Escrow. The module will create an invoice via the BulwarkX API and redirect the shopper to the returned payment URL.
